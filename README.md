# Moodzv.github.io

Personal portfolio of **Roberto Téllez Sánchez** — Level 1 IT Support / Help Desk, Mexico City.

**Live site:** https://moodzv.github.io

## What's here

A static site (plain HTML, CSS and JavaScript, no build step) presenting my
homelab projects, certifications and contact details. Each project links to a
short walkthrough video in English.

## Structure

```
index.html     markup and all page content
index.css      styles
index.js       keyboard-focus handling and the back-to-top button
fonts/         HK Grotesk and Jost
images/        header, favicon, icons and project screenshots
```

## Running it locally

No dependencies and no server required — open `index.html` in a browser.
